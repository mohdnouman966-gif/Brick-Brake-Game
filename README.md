A simple and interactive Brick Breaker Game built using HTML, CSS, and JavaScript. The player controls a paddle to bounce the ball and break all the bricks while trying to keep the ball from falling.

Features
* ❤️ 3 Lives system
* 🔄 Restart Game button
* 🏆 Score tracking
* 🎮 Paddle movement using Arrow Keys
* ❤️ 3 Lives system
* 🧱 Multiple bricks to break
* 🔄 Restart Game button
* 🎉 Win and Game Over messages
* 💻 Built with HTML, CSS & JavaScript

Technologies Used
* HTML5
* CSS3
* JavaScript
* HTML Canvas
